Boucles — Exercices dans la console

Les résultats de boucles.js apparaissent dans la console du navigateur.

On ouvre les outils de développement, puis l’onglet Console.

Après chaque modification, on enregistre le fichier JavaScript, on vide la console et on recharge cette page.

Le rechargement reprend les valeurs écrites dans le fichier. La page garde le même aspect pendant les exercices.
