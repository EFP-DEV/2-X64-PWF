**Point de départ :** la console de la page de Sullivan. Le travail sur les couleurs est terminé ; les deux nouvelles valeurs n’ont pas à modifier cette page.

Si vous avez déjà déclaré `hours` et `minutes` pendant cette activité, réutilisez-les et affectez-leur `13` et `37`, sans répéter `let`. Sinon, complétez et saisissez ce bloc une seule fois dans la page chargée :

```js
let hours;
let minutes;

hours = ___;
minutes = ___;
```

Prédisez, puis saisissez séparément les expressions suivantes. Indiquez si le résultat est un nombre ou du texte.

| Expression | Prédiction | Observation | Nombre ou texte ? |
|---|---|---|---|
| `37 + 1` | | | |
| `"37" + 1` | | | |
| `"13" + ":" + "37"` | | | |
| `hours + minutes` | | | |
| `hours + ":" + minutes` | | | |

Quelle différence les guillemets introduisent-ils ? Expliquez pourquoi le même opérateur `+` ne produit pas toujours une addition.

Pour repartir de zéro si la console signale une redéclaration, rechargez la page puis reprenez le bloc. Une fois les variables déclarées, utilisez des affectations sans répéter `let`.
