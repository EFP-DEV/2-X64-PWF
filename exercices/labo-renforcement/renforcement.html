Débogage et création

Les résultats du programme apparaissent dans la console du navigateur.

On ouvre les outils de développement avec F12, puis l’onglet Console.

La fiche de l’exercice indique le fichier JavaScript à charger dans cette page.

La page garde le même aspect quand le programme change. Un rechargement relance le programme à partir des valeurs écrites dans son fichier.
