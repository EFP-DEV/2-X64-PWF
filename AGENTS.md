# Lesson production rules

Follow the rules in this file when creating or updating lessons, exercises,
code examples, prototypes, and solutions in this repository.

## General rules

- Never launch a headless browser or create or run automated tests, including
  temporary test scripts. The user handles testing.
- Naming is important. Choose thoughtful, descriptive names that express purpose.
  Never use generic filenames such as `script.js`, `style.css`, or `css.css`,
  or similarly vague names that do not communicate what a file does.
- Do not define a function solely to call it once. Write that code directly
  where it needs to execute. Do not introduce a `main()` wrapper.
- Write French educational material in a descriptive voice: use “on” for
  actions and describe events and observable effects directly. Avoid “nous”,
  first-person plural imperatives, and possessives such as “notre” or “nos”;
  prefer concrete descriptions such as “le fichier” or “la couleur choisie”.
  Never address students directly: do not use “you”, “vous”, “tu”, their
  possessive forms, or second-person imperatives. For example, write
  “On clique sur l’image : l’ampoule s’allume.” Vary sentence subjects naturally
  instead of starting every sentence with “on”.
